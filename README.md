# RELAYBIT

Сайт-портфолио студии автоматизации Леонида Гусева.

RELAYBIT создаёт практичные инструменты на Python: Telegram-ботов, парсеры и мониторинг открытых данных, API-интеграции, AI-фильтрацию заявок и небольшие внутренние сервисы.

## Опубликованные кейсы

- Lead Hunter — поиск и оценка заданий с фриланс-площадок;
- Local Leads Scout — поиск и фильтрация публичных Telegram-сообществ;
- Telegram Game Bot — архивный игровой бот со связанными сценариями.

Каждый кейс основан на рабочем прототипе или готовой сборке. Исходный код публичных проектов не содержит токенов, файлов сессий и других секретов.

## Локальный запуск сайта

```bash
npm install
npm run dev
```

Производственная версия публикуется через GitHub Pages.
